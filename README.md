# TaskFlow Backend

Express + MongoDB Atlas API for TaskFlow, a role-based task management app.
Built as the companion project for the MERN stack course on La Excellence.

**Frontend repo:** https://github.com/<your-username>/taskflow-frontend

## Course progress tags

- `module-0-complete` - repo and folder structure set up
- `module-1-complete` - Atlas connection and schemas done
- `module-2-complete` - authentication and RBAC done
- `module-3-complete` - full API with assignment logic done
- `module-5-complete` - admin-only user list endpoint added, for the assignment picker
- `module-6-complete` - deployed live on Render

To jump to a module's starting point:
```
git checkout module-2-complete
```

## Setup

1. Copy `.env.example` to `.env` and fill in your MongoDB Atlas connection string
2. `npm install`
3. `npm run dev`
